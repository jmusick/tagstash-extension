Extension settings

Use the Tagstash API at https://tagsta.sh/api, or enter the URL for your own instance.

Dashboard

The Tagstash Dashboard shows your starred bookmarks and starred tags in one place. To make it your browser's start page, copy this address and paste it into your browser's home page or startup page setting.

Open

Chrome and Edge: Settings → On startup → Open a specific page. Firefox: Settings → Home → Homepage and new windows → Custom URLs. In Firefox the address is unique to this install, so copy it from here.
